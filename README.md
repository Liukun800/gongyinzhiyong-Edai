# 工银智涌 e贷

**基于Jev式判断与快慢协同的贷前材料核验引擎**

本项目面向数字金融赛道，聚焦材料归集后、综合审查前的资金用途一致性与经营陈述矛盾核验。通过规则检查、结构化判断、按需复杂分析和人工复核，将核验建议与材料证据、版本和责任记录连续交接。

## 核心设计

限定判断任务适配Jev式结构化输出；复杂问题保留分析入口，由人员确认后协同处理，并通过证据及办理记录承接。当前未启用自动升级。判断服务可以更换，业务任务与材料版本保持。核验完成不等同于贷款批准。

首期关注三项业务变化：成对原文可回看，补件后按新版本重跑，待处理事项带着证据和人员意见交给后续审查。相对工小审现有能力的新增必要性，需要同任务比较确认。

## 当前验证状态

截至2026年10月24日，云端判断后端采用蚂蚁数科LingDT-Decision-1.0，Jev式判断为结构化候选判断的方法称呼，未训练或微调基础权重。24项新编合成评价任务中，判断服务参考一致19/24，生成式分析17/24；分项为用途11/12与8/12、经营8/12与9/12。36项合成开发任务的平均接口响应分别为生成式分析1009.394毫秒、判断服务308.841毫秒、生成式判断723.418毫秒。开发任务与新编评价分别统计，费用尚未核实。

历史TypeSafe官方Jev两例协议连接、社区54份开发资料及28份挑战仍分别归档，不能与当前LingDT结果混用。参考标签尚未经独立业务复核，未形成银行人员工时、审批提速或完整成本收益实测。

软件流程与模型效果分别记录。完整成本、复核工时与工小审增量的采集模板位于[评审补证材料](docs/evidence-templates/)。

## 本地运行

Python 3.10及以上可运行不依赖模型的流程演示：

```powershell
python -X utf8 demo/app.py --mode simulation --port 8765
```

本地打开 http://127.0.0.1:8765/ 。当前已部署云端演示入口：普通流程为 http://123.207.241.109/ ，产品核验工作台为 http://123.207.241.109:8772/ 。工作台当前调用LingDT判断服务，保留可替换适配层；原产品网址和二维码入口保持不变。云端仅用于竞赛演示与受控仿真，不是工商银行生产系统。

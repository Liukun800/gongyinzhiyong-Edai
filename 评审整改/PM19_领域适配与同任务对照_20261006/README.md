# PM19 领域适配与同任务对照

目标：检验领域标签是否能改善结构化判断模型在两项仿真贷前材料核验任务上的表现，并与同任务的中文编码器、词面分类器及本地生成模型对照。

本阶段只使用 `demo/experiments/domain_dev_v2` 的54份项目自编仿真材料。28份旧挑战集不读取、不用于训练、调参或本次指标。54份的参考标签未经独立业务复核，所以所有模型比较只属于开发诊断。

## 预注册矩阵

- 规则基线：共享输入完整性规则；语义任务由规则处理的案例不调用语义模型。
- 冻结 AgentJev：公开 AgentJev-0.6B 编程完成度检查点，原样候选分布，作为迁移前基线。
- Jev式领域适配：冻结主干，仅在每个训练折中微调候选评分头；不是官方Jev训练，也不是信贷领域预训练。
- 中文模型对照：冻结 `bert-base-chinese` 编码器，按折拟合线性分类头；报告为线性探针/头部适配，不称全模型微调。
- 普通分类器对照：字符2—4元 TF-IDF + 逻辑回归，超参数固定。
- 生成模型对照：本地 Qwen2.5-0.5B-Instruct，以与两项任务相同的输入、答案候选及证据格式运行；它是本地替代模型，不是工银智涌。

所有对照使用相同输入检查、问题文本、答案集合、材料范围和答案到后续人工/补件动作的映射。开发诊断按任务内留一 lineage group 交叉验证，特征编码本身不读取答案；训练折之外的整组案例不能进入分类头拟合。自动放行始终关闭。

## 运行

```powershell
python demo/experiments/run_pm19_adaptation.py freeze
python demo/experiments/run_pm19_adaptation.py features
python demo/experiments/run_pm19_adaptation.py oof
python demo/experiments/run_pm19_adaptation.py qwen
```

模型按顺序运行以限制内存。`features` 和 `qwen` 阶段会逐例写进度文件；异常退出后可续跑。不得编辑、覆盖源数据或加载 `review_holdout_v1`。

## 银行环境边界

本轮没有工行测试租户、接口凭据、客户资料或安全域，不能进行真实银行环境验证。适配服务只在本机演示环境内测试认证失败、输入白名单、服务断连、审计失败回滚、人工接管和补件版本重跑。任何结果都应写为“本地隔离接口模拟”，不能写“工行系统接入/银行验收”。

## 判读限制

12个派生组和54份小样本不足以估计业务总体表现。参考标签源自项目作者，不是独立真值；不同模型规模、预训练语料与结构也不匹配。因此本试验只能回答：在当前仿真任务和固定开发折中，哪些实现值得继续获取独立业务标签与新样本验证。不得将一致数提升转成信贷风险改善、实际成本节约、审批时效或生产准确率。

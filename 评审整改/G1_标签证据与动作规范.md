# 两项核验任务的标签与动作规范

版本：remediation-v1。适用范围：仿真贷前材料核验，非授信审批。以下为项目任务定义，不是银行制度。

## 输入检查与语义判断分开

少于两份相关材料、主体缺失或不一致，以及经营材料期间缺失或不一致，由输入规则识别，进入待补充。规则不得推断文件真实性。

材料通过输入检查后，模型回答“信息不足/无法比较”只表明语义判断未完成，不能直接生成补件要求。存在的矛盾可能被误判为不足，须先进入复杂分析或人工核实。

## USE_MATCH 用途一致性

- 一致：同一申请资金范围内的有效材料支持相容的用途；允许同义表述、清晰的部分分配与不同付款阶段。
- 存在明确矛盾：同一范围的有效材料对资金用途作出无法同时成立的陈述；不能因缺少额外解释而抹去已明确的冲突。
- 信息不足：缺少对应关系、用途覆盖范围或其他必要文字证据，无法形成前两类结论。
- 有效更正可以改变比较依据；未签署草案、无效补充或其他申请的文件不能自动覆盖原材料。

## BIZ_CONFLICT 经营陈述矛盾

- 发现明确矛盾：在同主体、同期间、同业务口径下，两项有效陈述不能同时成立。
- 未发现明确矛盾：两项有效陈述可以同时成立；双方都表示停业也属于这一类。
- 无法比较：主体、期间、口径或证据不足以进行比较。
- “经营状况差”与“材料之间有矛盾”是不同问题；本任务只判断后一问题。

## 答案与动作

| 来源与条件 | 动作 | 说明 |
|---|---|---|
| 规则确认缺件/字段不足/不可比 | 待补充 | 记录可核查的缺项 |
| 轻量模型提示明确矛盾 | 人工核实 | 高分也不放行 |
| 轻量模型语义不足或较低原始分数 | 真实复杂分析；不可用则人工核实 | 0.80仅为本轮预设实验触发值，未经领域校准 |
| 轻量模型一致且满足实验分流条件 | 待复核 | 不等于自动完成，更不等于贷款通过 |
| 复杂分析有效且引用通过检查 | 待复核或人工核实 | 引用存在不等于语义支持已获验证 |
| 模型错误/无效结果/虚构引用 | 人工核实 | 保留失败信息和原始快模型输出 |

## 修复验收边界

本轮软件修复证明“语义不确定不再直接触发补件”及错误路径受控；不等于已提升矛盾识别准确率。旧错误及其衍生样本用于开发回归。专家标签复核与冻结新样本评价单独登记。
